# A股趋势突破选股模块 — 设计文档

日期:2026-08-05
状态:已确认(分节审批通过)

## 1. 背景与目标

现有系统是「自选股分析器」:给定 `STOCK_LIST` → 逐只拉历史/实时/筹码 → LLM 深度分析并推送决策仪表盘。它只分析用户指定的股票,**不会主动从全市场发现候选**。

本模块新增能力:**每日从全市场(仅 A 股)自动筛选出趋势突破型股票**,输出一份独立选股报告,不改变现有自选股分析行为。

### 已确认的决策
| 决策点 | 选择 |
|---|---|
| 市场范围 | 仅 A 股 |
| 选股风格 | 趋势突破型(MA5>MA10>MA20 多头排列、乖离率、量能),与现有内置纪律一致 |
| 使用方式 | 独立选股报告,不写入 STOCK_LIST、不并入个股分析管线 |
| 输出数量 | Top 5~10 |
| 报告深度 | 纯量化清单,不调用 LLM(无 Gemini Key 也可运行) |
| 触发方式 | 定时触发(`SELECTION_ENABLED=true`),本期不做 bot 命令/WebUI 手动触发 |

## 2. 架构与数据流

新增 `src/stock_selector.py`,单一职责、无状态,复用现有基础设施:

```
config.py          → SELECTION_ENABLED / SELECTION_TOP_N / 各筛选阈值
AkshareFetcher      → 全市场快照 + 逐只历史 K 线
stock_selector.py   → 两级漏斗 + 打分排序(纯函数,不碰外部服务)
formatters.py       → 选股报告 markdown
notification.py     → 推送(走现有多渠道)
scheduler.py        → 每日定时,在大盘复盘之后、个股分析之前触发
```

数据流:
1. `SELECTION_ENABLED=true` 时由调度器触发
2. **粗筛**:`stock_zh_a_spot_em()` 全市场快照(带缓存)→ 按快照字段过滤 → 候选池(~150 只)
3. **精筛**:对候选并发拉历史 K 线 → 算真实 MA/乖离率/量能 → 过滤 + 打分
4. 排序取 Top N → 格式化 → 推送独立报告

边界:选股模块只读数据、只输出报告,**不写 STOCK_LIST、不碰股票分析管线**。共享点仅为数据源与通知渠道。

## 3. 筛选规则

### 3.1 粗筛(全市场 5000+ → ~150,1 次快照调用)

| 规则 | 条件 | 理由 |
|---|---|---|
| 排除 ST/退市 | 名称含 `ST`/`退` | 避免退市风险票 |
| 只保留沪深主板 | 代码前缀 `600/601/603/605`(沪主板)或 `000/001/002/003`(深主板);排除创业板 `300/301`、科创 `688`、北交所 `8xx/4xx` | 流动性好、波动相对可控 |
| 排除停牌 | 最新价 > 0 | 买不进 |
| 排除涨停/跌停 | 涨跌幅在 `-5% ~ 8%` | 涨停买不进、跌停是风险 |
| 换手率 | `1% ~ 15%` | 活跃但非妖股 |
| 量比 | `1 ~ 8` | 放量但不异常过热 |
| 总市值 | `50亿 ~ 2000亿` | 排除微盘与超大盘 |
| 现价 | `3 ~ 50 元` | 可操作性 |

### 3.2 精筛(幸存者 → 达标者,逐只拉历史)

| 规则 | 条件 | 理由 |
|---|---|---|
| 排除新股 | 历史行数 ≥ 60 | 无趋势可言 |
| 多头排列 | `MA5 > MA10 > MA20` | 核心纪律 |
| 不追高 | 乖离率 `0% ~ 5%` | 偏离 MA5 超 5% 排除 |
| 量能配合 | 当日量 > 5日均量 ×1.1 | 上涨有量 |
| 趋势确认 | MA20 近 5 日抬升 | 中期趋势向上 |

### 3.3 打分排序(达标者取 Top N)

| 维度 | 得分 |
|---|---|
| 趋势强度 | 强势多头 +3 / 多头排列 +2 / 弱多头 +1 |
| 买点 | 乖离率 0~2% +2 / 2~5% +1 |
| 量能 | 量比 1.1~2 +1 / >2 +2(封顶) |

按总分降序取 `SELECTION_TOP_N`(默认 7)。

### 3.4 配置折中

- 粗筛核心阈值(市值/换手/量比/涨跌幅区间)做成 `.env` 可配
- 精筛规则与打分权重硬编码默认值,后续有需要再放开

## 4. 报告格式

复用现有 markdown 推送风格,单条推送不截断。

```
🎯 2026-08-05 今日选股 · A股趋势突破
从 5123 只中筛出达标 18 只,取 Top 7
候选池: 沪深主板 | 排除ST/新股/涨停

🔥 强势多头 | 红宝丽(002165)
📍 现价 18.52 | 多头排列 MA5>MA10>MA20
📈 乖离率 1.2% | 回踩MA5最佳买点
⚡ 量比 1.8 | 放量上攻

✅ 多头排列 | 华峰化学(002064)
📍 现价 7.85 | MA5>MA10>MA20
📈 乖离率 3.5% | 偏离略大,等回踩
⚡ 量比 1.4
...
---
生成时间: 18:00 | 仅供学习参考,不构成投资建议
```

每只展示:趋势类别(🔥强势多头 / ✅多头排列)、现价、多头排列状态、乖离率+买点提示、量比。顶部统计候选池规模,尾部免责声明与现有一致。

## 5. 错误处理、并发与测试

### 5.1 错误/边界处理
- **快照拉取失败**:`stock_zh_a_spot_em()` 失败 → 记录日志,本次选股中止(不推送),不影响当天其余任务(已有熔断器兜底)
- **个别历史拉取失败**:精筛中某只失败 → 跳过该只,不阻断整轮
- **候选池为空**:粗筛 / 精筛达标数为 0 → 不推送,只记日志(宁缺毋滥)
- **达标数不足 Top N**:有多少推多少,不补数
- **新股/数据不足**:历史 < 60 行视为新股排除;`MA20 为 NaN` 按不达标处理

### 5.2 并发与限流
- 精筛复用全局 `max_workers`(默认 3)串行拉取,沿用 `AkshareFetcher` 自带随机休眠 + 熔断,防封禁
- 快照复用现有 20 分钟缓存(若当日已有则直接命中,否则选股触发一次刷新)
- 精筛历史走各自缓存避免同轮重复

### 5.3 测试
- **单元测试**:筛选规则纯函数(粗筛过滤、精筛指标判定、打分排序、Top N 截断)——输入构造好的 DataFrame,不联网
- **边界覆盖**:涨停排除、ST 排除、代码前缀过滤(主板/创业/科创/北交)、乖离率 0% 与 5% 临界线、历史 < 60 行、空池
- **集成测试(可选)**:`SELECTION_ENABLED=true` 端到端跑一次,验证报告格式与推送 mock
