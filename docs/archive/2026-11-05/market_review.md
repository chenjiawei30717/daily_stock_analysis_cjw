# 🎯 大盘复盘

## 📊 2026-11-05 大盘复盘

### 一、市场总结
今日A股市场整体呈现普涨格局，三大指数悉数收红，其中深证成指和创业板指表现尤为强劲。市场活跃度显著提升，两市成交额突破2.1万亿元，个股涨多跌少，涨停家数众多，显示市场情绪积极。

### 二、指数点评
上证指数微涨0.10%，表现相对平淡，主要受权重股拖累或持稳影响。深证成指和创业板指分别上涨1.20%和0.87%，科创50更是大涨1.68%，表明市场资金更偏好成长股、科技股以及中小盘股，市场风格偏向活跃。

### 三、资金动向
两市成交额高达21351亿元，较前一交易日显著放量，显示市场交投活跃，增量资金入场意愿强烈。资金主要流向成长性板块，推动相关指数和个股走强。

### 四、热点解读
今日市场热点集中在新能车产业链上游，光伏辅材、光伏加工设备板块领涨，涨幅接近10%，显示资金对新能源赛道的追捧。视频媒体板块也表现突出。与此同时，动力煤、煤炭开采等传统能源板块领跌，表明市场资金正在进行高低切换，从周期股转向成长股。

### 五、后市展望
在成交量放大和市场情绪积极的背景下，预计短期市场有望延续偏强震荡格局。资金轮动效应明显，新能源、科技等成长板块有望继续活跃。但需关注上证指数能否跟上其他指数的步伐，以及市场热点能否持续扩散。

### 六、风险提示
需警惕部分热门板块短期涨幅过大，可能面临获利回吐压力。同时，尽管市场普涨，但仍有少数个股跌停，提示结构性风险依然存在。在缺乏明确市场新闻指引的情况下，需密切关注资金流向和板块轮动节奏。
